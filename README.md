👁️ AEYE — AI-Based Diabetic Retinopathy Detection System

Graduation Project — University of Technology and Applied Sciences (UTAS)
🚧 Status: In Progress — Model trained, refinement ongoing

An AI-powered medical imaging system that classifies diabetic retinopathy severity from retinal fundus images using Convolutional Neural Networks (CNNs). Designed to support early screening and reduce dependency on specialist availability in clinical settings.

🧠 What is Diabetic Retinopathy?
Diabetic retinopathy is a diabetes complication that damages the blood vessels in the retina and is a leading cause of blindness worldwide. Early detection through retinal screening is critical — but access to specialist ophthalmologists is limited in many regions. AEYE aims to automate this screening using AI.

⚙️ How It Works

Retinal fundus images are fed into the preprocessing pipeline (resizing, normalisation, augmentation)
A CNN model processes the image and extracts visual features associated with retinopathy
The model outputs a severity classification across standard DR grading levels
Results are surfaced as a classification output to support clinical decision-making


🎯 Key Features

Multi-class classification — grades DR severity across multiple stages
Image preprocessing pipeline — augmentation and normalisation for improved generalisation
Transfer learning — leveraging pretrained models to boost accuracy on limited data
End-to-end pipeline — from raw image input to classification output
